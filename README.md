# 🏔️ Trekking Arunachal Pradesh

> **Walk the wild eastern Himalaya of Arunachal Pradesh.**

A modern trekking and adventure travel platform focused exclusively on exploring the remote landscapes, high-altitude trails, valleys, forests, lakes, and mountain cultures of **Arunachal Pradesh, India**.

The platform allows travelers to discover treks, explore destinations, view detailed itineraries, check mountain weather, explore interactive trail maps, connect with the trekking community, and plan their next Arunachal adventure.

🌐 **Live Website:** https://trekkingarunachal.vercel.app/

---

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

### Clone the repository

```bash
git clone https://github.com/your-username/trekking-arunachal.git
```

### Navigate to the project

```bash
cd trekking-arunachal
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file in the project root.

```env
NEXT_PUBLIC_WEATHER_API_KEY=
NEXT_PUBLIC_MAP_API_KEY=
DATABASE_URL=
AI_API_KEY=
```

Add only the environment variables required by the services implemented in your project.

### Run the development server

```bash
npm run dev
```

Open the application at:

```text
http://localhost:3000
```

## 🚀 Production Build
